Brand — Splash & Icon

The two surfaces seen before any data exists. Both carry the same object: a red seal on receipt paper. The splash uses the outlined in-app seal; the icon uses a solid block, because 60px forgives nothing.

B1SplashCold open · one frozen frame

  • —Capacitor constraint: the splash is one static frozen frame — no spinner, no progress bar, no fade. Designed as a still, so nothing is lost when it is one.
  • —Status bar hidden. A cold open should show the brand, not the battery.
  • —The seal is the same object as the one in Home's header, scaled to 74px. One mark, two sizes — no separate launch logo.
  • —Same paper and grain as every screen, so the app does not cut to a different material at launch. Perforation near the bottom edge implies the tape continues past the frame.
  • —The whisper is optional and safe to drop — the frame still reads with the seal and wordmark alone.
