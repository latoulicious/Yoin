Yoin · mockup board 08 · 2026-09-22 · architecture, not UI

OTA update flow — web bundle over GitHub Releases, APK only for native changes

Yoin = Capacitor shell + Vite dist/ in a WebView. Today every change ships as a full APK on the rolling latest release, sideloaded by hand. Proposal: @capgo/capacitor-updater in self-host mode. CI zips dist/ next to the APK; the app pulls the zip at boot and swaps it on next launch. APK rebuild only when android/**, plugins, or Capacitor itself change. No Capgo cloud, no server — GitHub Releases is the update server.

B · App boot sequence
capgo self-host · pull model
Plugin runs with autoUpdate: false. Yoin owns the check: one fetch of manifest.json, compare, download, mark next. The current session never swaps mid-use; the new bundle lands on the following launch. Rollback is the plugin's own: a bundle that never calls notifyAppReady() is reverted automatically.

D · Constraints that bite
before wiring it
  • Version becomes two numbers. package.json version = bundle version (OTA compares this). Android versionCode = native version (manifest minNative compares this). Bump bundle every release; bump versionCode only on APK release.
  • Builtin bundle goes stale. The APK still ships the dist/ it was built with. Fresh install or rollback lands on that, then OTA catches up on next boot. Acceptable for one user.
  • Manifest URL must be stable. github.com/<owner>/yoin/releases/download/latest/manifest.json works because the release tag is force-moved, same trick as today's APK. GitHub redirects to a CDN URL; plugin follows redirects.
  • Offline boot must not block. Manifest fetch is fire-and-forget after notifyAppReady(). No network → app runs current bundle. No spinner, no retry loop.
  • sha256 in manifest, not optional. Self-host mode has no signing by default; checksum is the only integrity check. CI computes it from the exact zip it uploads.
  • Two workflows or one with two jobs. Keep android.yml as is, gate the gradle job on native paths, add a lightweight bundle job that always runs. Both write to the same latest release; APK job must not clobber manifest.json.
  • Rejected: Ionic Appflow Live Updates (paid, no self-host). Custom updater (re-implements checksum, atomic swap, rollback for no gain). Capgo cloud (fine, but a third party in the loop for one phone).
